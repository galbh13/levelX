# Calisthenics Training App

A gamified training platform for Gal's calisthenics students.

**Status:** Active — planning & early development
**Target launch:** ~June 2026

## Core Features (v1)
- Video gallery — exercise library with instructional videos
- Skill tree — calisthenics progression system
- Community chat — student community
- Trainer-coach chat — Gal ↔ student direct messaging
