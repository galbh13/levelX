# Work & Business

**Type:** Solo developer / personal trainer
**Main Project:** Gamified calisthenics training web app (name TBD)

## What the App Does
A platform for Gal's calisthenics students that makes training feel like a game.

**Core Features (v1):**
- Video gallery — exercise library with instructional videos
- Skill tree — progress system based on calisthenics movements
- Community chat — students connect with each other
- Trainer-coach chat — direct line between Gal and each student

More features will be added as the product evolves.

## Stack & Tools
- Editor: VS Code
- MCP servers: None

## Target
Simple, clean, easy to use — for both Gal and his students.
Soft launch target: ~June 2026
